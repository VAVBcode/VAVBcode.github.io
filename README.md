# 🌐 Portafolio web | Víctor Villacís

Portafolio personal de **Víctor Villacís**, estudiante de Ingeniería en Ciencia de Datos e Inteligencia Artificial en la ESPOL. Reúne mi presentación, mis habilidades, mis proyectos y mis canales de contacto.

🔗 **Sitio en vivo:** [vavbcode.github.io](https://vavbcode.github.io)

## 🛠️ Tecnologías

- **HTML5** para la estructura semántica.
- **CSS3** para el diseño oscuro y responsivo, con variables CSS y Grid/Flexbox.
- **JavaScript** (sin frameworks) para el menú móvil y detalles de la página.
- **Google Fonts:** Space Grotesk y JetBrains Mono.
- **GitHub Pages** para el despliegue.

## 🚀 Ejecutar en local

1. Clona el repositorio:
   ```bash
   git clone https://github.com/VAVBcode/VAVBcode.github.io.git
   ```
2. Abre `index.html` en tu navegador. No requiere instalación ni compilación.
